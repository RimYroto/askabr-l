1. СИСТЕМНЫЕ ТРЕБОВАНИЯ
================================================================================

Программа распространяется в виде исходного кода и запускается средствами
менеджера зависимостей uv. Отдельный исполняемый установщик не предусмотрен.

  Параметр              Требование
  --------------------  --------------------------------------------------
  ОС                    Windows 10/11 (64-bit), macOS 12+, Linux (64-bit)
  Оперативная память    не менее 8 ГБ (рекомендуется 16 ГБ)
  Дисковое пространство не менее 5–8 ГБ (зависимости — около 2–3 ГБ)
  Сеть                  требуется при первичной установке компонентов
  Дисплей               разрешение не ниже 1280×720

В составе дистрибутива должны присутствовать файлы весов нейросети:

  models/tomato/model_v1.0.0.pt   (допускается имя best.pt)
  models/pear/model_v1.0.0.pt     (допускается имя best.pt)

При отсутствии указанных файлов графический интерфейс откроется, однако
список доступных культур будет пуст.

2. ПОЛУЧЕНИЕ ДИСТРИБУТИВА ПРОЕКТА
================================================================================

Необходимо получить полный каталог проекта, а не отдельные файлы из него.

Способ 1 — архив (ZIP)

  1. Загрузите архив репозитория или получите его от поставщика.
  2. Распакуйте архив в выбранный каталог на диске.
  3. Зафиксируйте полный путь к корневому каталогу проекта, например:
       Windows:  C:\Users\<имя_пользователя>\Documents\<каталог_проекта>
       macOS:    /Users/<имя_пользователя>/<каталог_проекта>
       Linux:    /home/<имя_пользователя>/<каталог_проекта>

Способ 2 — система контроля версий Git

    git clone <URL-репозитория>
    cd <каталог_проекта>

Признаки корректного дистрибутива: в корне присутствуют каталоги askabr,
gui, models, docs и файл pyproject.toml. Неполный набор файлов указывает
на ошибку копирования — повторите получение дистрибутива.

3. УСТАНОВКА И ПЕРВЫЙ ЗАПУСК (WINDOWS)
================================================================================

3.1. Командная оболочка

  Для выполнения команд установки используется Windows PowerShell
  (или Терминал Windows). Запуск: меню «Пуск» → «Терминал» / «PowerShell».

  Ввод команд завершается клавишей Enter. Приглашение оболочки имеет вид:
  PS <текущий_каталог>>

3.2. Установка менеджера uv

  uv обеспечивает установку интерпретатора Python 3.14, создание
  виртуального окружения и развёртывание зависимостей проекта.

  В PowerShell выполните (одной строкой):

  powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

  По завершении закройте и вновь откройте окно PowerShell.

  Проверка:

    uv --version

  Ожидаемый результат — строка с номером версии uv (например, uv 0.x.x).

  При сообщении о неизвестной команде: перезагрузите систему и повторите
  проверку в новом сеансе PowerShell.

3.3. Переход в каталог проекта

  Команда cd задаёт рабочий каталог. Подставьте фактический путь
  к корню проекта на данном компьютере.

  Примеры (путь необходимо заменить):

    cd $HOME\Documents\<каталог_проекта>
    cd $HOME\Desktop\<каталог_проекта>

  Если путь содержит пробелы, заключите его в кавычки:

    cd "C:\Users\<имя_пользователя>\Documents\<каталог_проекта>"

  Контроль наличия дистрибутива:

    dir pyproject.toml
    dir models

3.4. Установка зависимостей

  Из корневого каталога проекта выполните:

    uv sync

  В процессе выполняются: загрузка Python 3.14 (при отсутствии),
  создание каталога .venv, установка PyTorch, PyQt6 и прочих пакетов.

  Первичная установка занимает 10–25 минут и требует сетевого доступа
  (объём загрузки порядка 2–3 ГБ). Дождитесь возврата приглашения оболочки.

  При сбоях сети повторите команду uv sync.

3.5. Запуск графического интерфейса

    uv run askabr-gui

  Должно отобразиться окно приложения «АСКАБР-Л». Первый запуск может
  занять до одной минуты. При отсутствии окна см. раздел 10.

3.6. Альтернативная установка (без uv)

  При невозможности использования uv:

  1. Установите Python 3.14 с https://www.python.org/downloads/
     с включённой опцией добавления в PATH.
  2. В каталоге проекта:

    py -3.14 -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -U pip
    pip install -e .
    askabr-gui

================================================================================
4. УСТАНОВКА И ЗАПУСК (macOS)
================================================================================

4.1. Запустите приложение «Терминал».

4.2. Установка uv:

  curl -LsSf https://astral.sh/uv/install.sh | sh

  Перезапустите сеанс терминала. Проверка: uv --version

4.3. Переход в каталог проекта (подставьте фактический путь):

  cd ~/<каталог_проекта>

4.4. Установка и запуск:

  uv sync
  uv run askabr-gui

  На системах с процессором Apple Silicon при наличии поддержки может
  использоваться ускорение MPS.

================================================================================
5. УСТАНОВКА И ЗАПУСК (LINUX)
================================================================================

5.1. Системные библиотеки (Ubuntu/Debian):

  sudo apt update
  sudo apt install -y libxcb-cursor0 libxkbcommon-x11-0 libgl1

5.2. Установка uv:

  curl -LsSf https://astral.sh/uv/install.sh | sh
  source $HOME/.local/bin/env
  uv --version

5.3. В каталоге проекта (подставьте фактический путь):

  cd ~/<каталог_проекта>
  uv sync
  uv run askabr-gui

  На иных дистрибутивах при необходимости установите пакеты Qt/X11
  средствами менеджера пакетов ОС.

================================================================================
6. РЕГУЛЯРНЫЙ ЗАПУСК ПРОГРАММЫ
================================================================================

Первичная установка (uv sync) выполняется однократно. Для последующих сеансов:

  1. Откройте PowerShell (Windows) или терминал (macOS/Linux).
  2. Перейдите в корневой каталог проекта:
       cd <путь_к_каталогу_проекта>
  3. Запустите приложение:
       uv run askabr-gui

  Команда uv run активирует окружение .venv автоматически.

  После обновления дистрибутива (git pull или новый архив) однократно
  выполните uv sync, затем uv run askabr-gui.

================================================================================
7. ПРОВЕРКА РАБОТОСПОСОБНОСТИ
================================================================================

  1. Выполните uv run askabr-gui.
  2. В поле «Культура» должны отображаться «Томат» и/или «Груша».
  3. Выберите «Открыть изображение», укажите файл JPG или PNG.
  4. Нажмите «Выполнить классификацию».
  5. В области «Результат классификации» должны появиться класс
     и значение уверенности.

При пустом списке культур или коде ошибки E004 проверьте наличие файлов
весов в models/tomato/ и models/pear/ (model_v1.0.0.pt или best.pt).

Дополнительная проверка без GUI:

  uv run python -c "from gui.variants import available_variants; print(available_variants())"

  Ожидаемый вывод содержит идентификаторы доступных моделей, например
  ['tomato', 'pear'].

8. РАБОТА С ПРОГРАММОЙ
================================================================================

8.1. Элементы окна

  Элемент                      Назначение
  ---------------------------  ------------------------------------------
  Культура                     Выбор модели: томат, груша
  Открыть изображение          Загрузка одного снимка
  Открыть серию изображений    Загрузка нескольких снимков
  Выполнить классификацию      Запуск анализа
  Экспорт отчёта               Сохранение результатов в текстовый файл
  Предпросмотр                 Отображение загруженного снимка
  Результат классификации      Итог по первому изображению
  Сводка по серии              Итог по серии (ИФС)
  Топ-5 классов                Пять наиболее вероятных классов

8.2. Меню

  Файл    — открытие изображений, экспорт отчёта, выход.
  Анализ  — запуск классификации.
  Справка — настоящая инструкция, сведения о программе, ограничения ИФС.

8.3. Анализ одного изображения

  1. Выберите культуру.
  2. «Открыть изображение» — файл PNG, JPG, JPEG или BMP.
  3. Убедитесь в корректности предпросмотра.
  4. «Выполнить классификацию».
  5. Ознакомьтесь с результатом и таблицей «Топ-5 классов».

8.4. Анализ серии изображений

  1. Выберите культуру.
  2. «Открыть серию изображений» — выделите несколько файлов.
  3. «Выполнить классификацию».
  4. «Результат классификации» — по первому снимку;
     «Сводка по серии» — индекс по всей серии.

8.5. Сохранение отчёта

  После классификации: «Экспорт отчёта» → укажите имя файла → откройте
  сохранённый текстовый файл в редакторе.

8.6. Требования к снимкам

  - Лист в кадре крупным планом, равномерное освещение.
  - Лист занимает основную часть изображения.
  - Отсутствие сильных бликов, размытия, глубоких теней.
  - Формат JPG или PNG.

8.7. Завершение работы

  Закрытие окна или пункт меню «Файл → Выход».

9. РАСШИФРОВКА РЕЗУЛЬТАТОВ
================================================================================

  Показатель                   Содержание
  ---------------------------  ------------------------------------------
  Предполагаемый класс         Наиболее вероятное состояние листа
  Уверенность модели, %        Степень уверенности классификатора
  ИНК, %                       Индекс неопределённости между классами
  ИФС                          Индекс фитосанитарного состояния (0–100)
                               по серии снимков
  Топ-5 классов                Пять наиболее вероятных классов с долями

  Результат носит вспомогательный характер и не заменяет осмотр
  специалиста и лабораторную диагностику.

10. УСТРАНЕНИЕ НЕПОЛАДОК
================================================================================

  Симптом                               Действия
  ------------------------------------  ------------------------------------
  Команда uv не найдена (Windows)       Повторите установку uv (п. 3.2),
                                        перезагрузите систему

  Команда uv не найдена (macOS/Linux)   Повторите установку (п. 4.2 / 5.2),
                                        выполните source $HOME/.local/bin/env

  Ошибка перехода в каталог (cd)        Уточните путь в файловом менеджере,
                                        используйте кавычки при пробелах

  uv sync — сбой сети / таймаут         Проверьте подключение, повторите uv sync

  uv sync — недостаточно места          Освободите не менее 5 ГБ на диске

  GUI не открывается (Linux)            Установите библиотеки Qt (п. 5.1)

  Пустой список культур / E004          Разместите model_v1.0.0.pt или best.pt
                                        в models/tomato и models/pear

  E002 — неподдерживаемый формат        Используйте PNG или JPG

  E003 — ошибка чтения файла            Проверьте целостность файла, закройте
                                        сторонние программы, использующие его

  E005 — ошибка классификации           Другой снимок; перезапуск askabr-gui

  E005, certificate_verify_failed       uv sync, затем uv run askabr-gui

  PowerShell: запрет выполнения         Set-ExecutionPolicy -Scope CurrentUser
  сценариев                             RemoteSigned; повторите п. 3.2

  Сбой после обновления репозитория     uv sync, uv run askabr-gui

  python / py не найдены (без uv)       Установите Python 3.14 с PATH (п. 3.6)
