1. УСТАНОВКА ГОТОВОЙ ПРОГРАММЫ (WINDOWS)
================================================================================

Этот способ подходит, если вы получили один файл ASKABR-L.exe.
Дополнительное ПО устанавливать не нужно.

1.1. Что понадобится

  Параметр              Требование
  --------------------  ------------------------------------------
  ОС                    Windows 10 или 11 (64-bit)
  Оперативная память    8 ГБ и более
  Свободное место       1 ГБ
  Экран                 Разрешение не ниже 1280x720

1.2. Шаги установки

  1. Получите файл программы ASKABR-L.exe
     (после сборки он лежит в папке dist, либо передаётся отдельно).

  2. Создайте папку для программы, например:
     C:\Users\ИмяПользователя\Documents\ASKABR-L\

  3. Скопируйте файл ASKABR-L.exe в эту папку.

  4. Запустите программу двойным щелчком по ASKABR-L.exe.

  При первом запуске программа может загружаться 1-3 минуты — это нормально:
  распаковываются внутренние компоненты.

  Рядом с .exe можно положить файл INSTRUKCIYA.txt (из папки docs проекта)
  для справки вне программы. В самой программе инструкция доступна в меню
  Справка -> Инструкция.

1.3. Предупреждение Windows при первом запуске

  Windows может показать окно «Система Windows защитила ваш компьютер»:

  1. Нажмите «Подробнее».
  2. Нажмите «Выполнить».

  Это стандартное поведение для программ без платной цифровой подписи Microsoft.
  После подтверждения программа запустится.

1.4. Если появляется ошибка про DLL или MSVCP

  1. Откройте в браузере:
     https://learn.microsoft.com/ru-ru/cpp/windows/latest-supported-vc-redist

  2. Скачайте vc_redist.x64.exe (Visual C++ Redistributable для 64-bit).

  3. Установите его и перезагрузите компьютер.

  4. Снова запустите ASKABR-L.exe.

1.5. Брандмауэр и антивирус

  Программа не требует интернета для анализа изображений.
  Антивирус может проверять .exe при первом запуске — дождитесь окончания
  проверки.

2. УСТАНОВКА ИЗ ИСХОДНИКОВ (WINDOWS)
================================================================================

Этот способ нужен, если у вас есть папка с исходным кодом проекта
(например, askabr-l) и вы хотите запускать программу через Python.

2.1. Что понадобится

  - Windows 10/11 (64-bit)
  - Папка проекта целиком (вместе с подпапкой models/, где лежат файлы моделей)
  - Python 3.14
  - Менеджер пакетов uv (рекомендуется) или pip

2.2. Установка Python

  1. Откройте https://www.python.org/downloads/
  2. Скачайте установщик Python 3.14 для Windows.
  3. При установке обязательно отметьте галочку «Add python.exe to PATH».
  4. Завершите установку.

  Проверка в командной строке (Win+R -> cmd -> Enter):

    py -3.14 --version

  Должно появиться Python 3.14.x. Команда py -3.14 предпочтительна при сборке .exe.

2.3. Установка uv (рекомендуется)

  Откройте PowerShell и выполните:

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

  Закройте и снова откройте PowerShell, затем проверьте:

    uv --version

2.4. Установка зависимостей проекта

  1. Откройте PowerShell или командную строку.
  2. Перейдите в папку проекта:

    cd C:\путь\к\askabr-l

  3. Установите зависимости:

    uv sync

  Команда создаст виртуальное окружение и установит PyTorch, PyQt6 и остальные
  компоненты. Первая установка может занять 10-20 минут (скачивается PyTorch,
  около 1-2 ГБ).

2.5. Запуск программы

  Из той же папки проекта:

    uv run askabr-gui

  Или после активации окружения:

    .venv\Scripts\activate
    askabr-gui

2.6. Альтернатива без uv (только pip)

    cd C:\путь\к\askabr-l
    python -m venv .venv
    .venv\Scripts\activate
    pip install -U pip
    pip install -e .
    askabr-gui

3. УСТАНОВКА ИЗ ИСХОДНИКОВ (macOS)
================================================================================

3.1. Что понадобится

  - macOS 12 (Monterey) или новее
  - Папка проекта с подпапкой models/
  - Python 3.14 и uv

3.2. Установка uv

  В терминале (Terminal.app):

    curl -LsSf https://astral.sh/uv/install.sh | sh

  Перезапустите терминал и проверьте:

    uv --version

  Если Python не установлен, uv может установить его автоматически при первом
  uv sync.

3.3. Установка и запуск

    cd ~/путь/к/askabr-l
    uv sync
    uv run askabr-gui

  На Mac с процессором Apple Silicon (M1/M2/M3) программа автоматически
  использует GPU (MPS), если он доступен.

4. УСТАНОВКА ИЗ ИСХОДНИКОВ (LINUX)
================================================================================

4.1. Что понадобится

  - Ubuntu 22.04+ или аналогичный дистрибутив (64-bit)
  - Папка проекта с подпапкой models/
  - Python 3.14 и uv

4.2. Системные библиотеки для GUI

  Для PyQt6 на Ubuntu/Debian:

    sudo apt update
    sudo apt install -y libxcb-cursor0 libxkbcommon-x11-0 libgl1

  На других дистрибутивах могут понадобиться пакеты Qt/X11 — установите их
  через менеджер пакетов вашей системы.

4.3. Установка uv

    curl -LsSf https://astral.sh/uv/install.sh | sh
    source $HOME/.local/bin/env
    uv --version

4.4. Установка и запуск

    cd ~/путь/к/askabr-l
    uv sync
    uv run askabr-gui

5. СБОРКА ASKABR-L.EXE
================================================================================

Сборка выполняется только на Windows 10/11 (64-bit).
На macOS и Linux .exe собрать нельзя.

5.1. Что понадобится

  - Windows 10/11 x64
  - Python 3.14 (https://www.python.org/downloads/), с галочкой Add to PATH
  - Папка проекта с моделями в models/tomato/ и models/pear/
    (файлы best.pt или model_v1.0.0.pt)

5.2. Сборка одной командой

  1. Откройте cmd или PowerShell.
  2. Перейдите в папку проекта:

    cd C:\путь\к\askabr-l

  3. Запустите сборку (любой способ):

    packaging\build_windows.cmd
    packaging\build_windows.bat
    .\packaging\build_windows.ps1
    py -3.14 packaging\build_windows.py

  Скрипт автоматически:
  - создаст временное окружение .venv-build;
  - установит PyTorch (CPU), PyInstaller и зависимости проекта;
  - соберёт один файл dist\ASKABR-L.exe.

  Сборка занимает 15-40 минут и требует 3-5 ГБ свободного места.

5.3. Результат

  Файл                  Описание
  --------------------  ------------------------------------------
  dist\ASKABR-L.exe     Готовая программа (около 400-800 МБ)

  Скопируйте ASKABR-L.exe на целевой компьютер — больше ничего устанавливать
  не нужно. Рекомендуется положить рядом файл INSTRUKCIYA.txt.

5.4. Сборка из cmd или PowerShell

  Командная строка (cmd):

    cd C:\путь\к\askabr-l
    packaging\build_windows.cmd

  PowerShell:

    cd C:\путь\к\askabr-l
    .\packaging\build_windows.ps1

  Если PowerShell блокирует .ps1:

    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

  Или двойной щелчок по packaging\build_windows.bat (вызывает .cmd).

6. ПРОВЕРКА УСТАНОВКИ
================================================================================

После установки любым способом:

  1. Запустите программу.
  2. В списке «Культура» должны быть доступны «Томат» и/или «Груша».
  3. Нажмите «Открыть изображение», выберите любой снимок листа (JPG/PNG).
  4. Нажмите «Выполнить классификацию».
  5. В блоке «Результат классификации» должны появиться название класса
     и процент уверенности.

Если список культур пуст или появляется ошибка E004, проверьте наличие файлов:

  models/tomato/best.pt
  models/pear/best.pt

(или model_v1.0.0.pt — оба имени поддерживаются)

7. РАБОТА С ПРОГРАММОЙ
================================================================================

7.1. Элементы окна

  Элемент                      Назначение
  ---------------------------  ------------------------------------------
  Культура                     Выбор модели: томат, груша
  Открыть изображение          Загрузка одного снимка
  Открыть серию изображений    Загрузка нескольких снимков
  Выполнить классификацию      Запуск анализа
  Экспорт отчёта               Сохранение результатов в .txt
  Предпросмотр                 Просмотр загруженного снимка
  Результат классификации      Итог по первому изображению
  Сводка по серии              Итог по всей серии (ИФС)
  Топ-5 классов                Пять наиболее вероятных диагнозов

7.2. Меню

  Файл    — открытие изображений, экспорт отчёта, выход.
  Анализ  — запуск классификации.
  Справка — инструкция, сведения о программе, ограничения ИФС.

7.3. Анализ одного изображения

  1. Выберите «Культуру» (например, «Томат»).
  2. «Открыть изображение» -> выберите файл (PNG, JPG, JPEG, BMP).
  3. Убедитесь, что снимок виден в предпросмотре.
  4. «Выполнить классификацию».
  5. Изучите результат и таблицу «Топ-5 классов».

7.4. Анализ серии изображений

  1. Выберите «Культуру».
  2. «Открыть серию изображений» -> выделите несколько файлов
     (Ctrl — по одному, Shift — диапазон).
  3. «Выполнить классификацию».
  4. «Результат классификации» — по первому снимку;
     «Сводка по серии» — ИФС по всей серии.

7.5. Сохранение отчёта

  1. После классификации нажмите «Экспорт отчёта».
  2. Укажите имя файла (например, askabr_report.txt).
  3. Откройте отчёт в Блокноте или любом текстовом редакторе.

7.6. Рекомендации по снимкам

  - Лист крупным планом, при ровном освещении.
  - Лист занимает большую часть кадра.
  - Без сильных бликов, размытия и глубоких теней.
  - Формат JPG или PNG.

7.7. Выход

  Закройте окно (кнопка X) или выберите «Файл -> Выход».

8. РАСШИФРОВКА РЕЗУЛЬТАТОВ
================================================================================

  Показатель                   Что означает
  ---------------------------  ------------------------------------------
  Предполагаемый класс         Наиболее вероятное состояние листа
  Уверенность модели, %        Насколько модель уверена (выше — надёжнее)
  ИНК, %                       Индекс неопределённости: высокое значение —
                               модель сомневается между классами
  ИФС                          Индекс фитосанитарного состояния (0-100)
                               по серии; выше — лучше общая картина
  Топ-5 классов                Пять наиболее вероятных диагнозов с процентами

  ВАЖНО: результат — автоматическая оценка по фото. Она не заменяет осмотр
  специалиста и лабораторную диагностику.

9. УСТРАНЕНИЕ НЕПОЛАДОК
================================================================================

  Проблема                              Решение
  ------------------------------------  ------------------------------------
  Программа не запускается (Windows)    Установите Visual C++ Redistributable
                                        x64, перезагрузите ПК
                                        (см. раздел 1.4)

  «Windows защитил ваш компьютер»       Подробнее -> Выполнить

  Долгий первый запуск .exe             Подождите 1-3 минуты

  Пустой список культур / E004          Проверьте models/tomato/best.pt
                                        и models/pear/best.pt

  E002 — неподдерживаемый формат        Сохраните снимок как PNG или JPG

  E003 — не удалось прочитать файл      Файл повреждён или заблокирован

  E005 — ошибка классификации           Другое изображение или перезапуск

  E005 с текстом certificate_verify_   Обновите проект (исправлено в новых
  failed / SSL                          версиях) или выполните:
                                        uv sync
                                        uv run askabr-gui
                                        При обучении: pip install certifi

  uv: command not found                 Переустановите uv (раздел 2.3 или 3.2)

  python: command not found             Переустановите Python с Add to PATH

  Ошибка при uv sync                    Проверьте интернет; освободите 2+ ГБ

  GUI не открывается на Linux           Установите библиотеки Qt (раздел 4.2)

  Ошибка при сборке .exe                Python 3.14 (py -3.14 --version),
                                        модели в models/, затем
                                        packaging\build_windows.cmd
